# Regex

虽然真的很难懂，但是确实用处很多，也逃不开它的魔爪。记录一点常用的写法，避免临时查找的regex有太多bug。测试工具推荐https://regex101.com/，有解释regex的意思，容易debug。

- [^a-zA-Z\d\s:"\{\}_,] ：单个字符是否是特别字符，`{"a_b":"c", ""}`这样正常的json是不会查出特别的，回车tab等也用`\s`囊括了。想要更多字符不被查出来，就一个一个加到中括号里的尾部。

hive的regexp_replace好像不是遵守java的regex规则，比如dash '-'不需要转义，但是java里需要转义？
'\\\-\'\"'这样的写法，hive里还会报错，得把\-换回原始-，才能正常运行？
